I'm a **penetration tester and security professional**. I assess what I'm authorised to test — networks, web and APIs, cloud, Active Directory and wireless — and I work across **GRC (governance, risk and compliance)** too. Then I turn what I learn into things other people can use: open-source tooling, practitioner handbooks, templates and peer-reviewed research.

This profile is a **growing home for that work** — all my own, built in the open. It identifies and defends; nothing here carries a client's name.

### What I do

- **Offensive & assessment** — penetration testing and credentialed assessment across network, web/API, cloud, Active Directory and wireless.
- **GRC** — governance, risk and compliance: assessments, controls mapping, and reusable templates *(collection growing here)*.
- **Building** — evidence-first security tooling in Python and PowerShell, designed to be deterministic and auditable.
- **Teaching & research** — a full ethical-hacking lab curriculum, a network-assessment handbook, and web-security measurement research.

### Featured work

| Project | What it is |
|---|---|
| **[network-security-assessment-handbook](https://github.com/abdullahzarshaid/network-security-assessment-handbook)** | A 138-page practitioner's handbook — from networking fundamentals to network, wireless, web, API, cloud and directory assessment. Grounded in NIST 800-115, PTES, OWASP and MITRE ATT&CK. |
| **[ethical-hacking-labs](https://github.com/abdullahzarshaid/ethical-hacking-labs)** | A hands-on ethical-hacking knowledge base — 19 modules across the attack lifecycle, each a runnable lab guide with its own command cheat-sheet. |
| **[posturekit](https://github.com/abdullahzarshaid/posturekit)** | Evidence-first, credentialed Windows & network **posture assessment** — reads facts read-only, seals them with a SHA-256 manifest, and evaluates them against a transparent rule set. No black box. |
| **[evidencegate](https://github.com/abdullahzarshaid/evidencegate)** | An evidence-first ledger + deterministic release gate for security findings — the database refuses to confirm a finding without hashed proof, and one command re-verifies integrity, CVSS, scope and secrets. |
| **[CWE613Study](https://github.com/abdullahzarshaid/CWE613Study)** | Research data and code for *"Logout Is Not Expiration: A Source-Aware Semantic Characterization of CWE-613"* — a measurement study of session-termination weaknesses. |

> More on the way — **GRC templates**, assessment checklists and further tooling.
